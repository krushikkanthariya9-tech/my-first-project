HelloWorld — My First Java Project

A beginner-friendly Java project created while learning programming and GitHub.

About the Project

This project is a simple Java console application that displays a welcome message and basic information about my learning journey.

Features

- Displays a welcome message.
- Demonstrates Java's "main()" method.
- Uses a "String" variable.
- Prints text using "System.out.println()".

Technologies Used

- Java
- OpenJDK 21
- GitHub

How to Run

1. Install Java Development Kit (JDK) 21 or a compatible version.

2. Download "HelloWorld.java" from this repository.

3. Open a terminal in the folder containing the file.

4. Compile the program:
   
   javac HelloWorld.java

5. Run the program:
   
   java HelloWorld
